# Synthetic explorer demonstration

This is a developer preview of the current source, **not an installed product or
scientific acceptance fixture**. It is excluded from release packaging. Do not
point it at a Vault, project, registry or existing populated folder.

From the development checkout, create an empty disposable directory:

```sh
rtk proxy mktemp -d build/explorer-demo.XXXXXX
```

Pass that exact returned directory to the source demonstration:

```sh
rtk proxy uv run --offline --frozen python dev-guide/demos/knowledge_explorer.py --root build/RETURNED_DIRECTORY
```

The foreground process reports a loopback URL and a separate session fragment.
Open `URL#SESSION_FRAGMENT` locally. That fragment is a session credential; do not
publish or put it in screenshots, reports or committed files. Stop this process
with Ctrl-C. It neither starts nor stops an installed service or the old preview.
The OS chooses a new port.

## What to inspect

1. Initially there are three synthetic paper units and one branched relationship
   path. Four conditional records do not produce four paper nodes.
2. Select paper A. Its information note, analysis reading fragment, image,
   configuration and explicitly unavailable Canvas remain one unit's asset list.
   The fragment is not a full paper analysis and the absent Canvas is not a fake
   accepted tree. Preview the analysis to inspect the folded quotation, direct
   evidence emphasis, adjacent conditions/results and illustrative image/caption.
3. Select the saved common-base/prediction view and the **conditions/results** tab.
   Selecting base A and the control task together must match nothing: paper A's
   separate base-A/prediction and base-B/control records cannot be mixed.
4. Reference paper D from the synthetic Field. Apply and save: all five declared
   assets join as one fourth paper, without changing any owned file. The same
   qualified unit cannot be duplicated by choosing it again.
5. Edit outer positioning, a relationship or a conditional record; add a dimension
   if useful. These changes belong only to the disposable exploration manifest.

All names, dates, numbers, quotations and relationships are synthetic, not claims
about real literature. No actual PDF is supplied. All native launches are denied,
including direct HTTP requests; no real Source registry, Zotero API, Obsidian
configuration or account secret is read. Availability diagnostics are intentional.
This demonstration does not establish native reading, installation, human approval,
fresh-chat one-shot analysis or the overall project goal.

# 文献关系边证据规范

## 允许的关系类型

| 类型 | 含义 | 仅引用可证明？ |
|---|---|---|
| `cites` | A 引用了 B | 是 |
| `follow-up` | A 在 B 的基础上延续研究 | 否，需正文证据 |
| `method-extension` | A 扩展了 B 的方法 | 否，需正文证据 |
| `representation-shift` | A 改变了 B 引入的表示方式 | 否，需正文证据 |
| `benchmark-successor` | A 取代 B 成为新基准 | 否，需引用量 + 正文证据 |
| `contradicts` | A 的发现与 B 矛盾或推翻 B | 否，需正文明确表述 |

## 证据要求

- `cites`：无需额外证据，引用关系本身即为证据
- 其他所有类型：必须提供至少一条 `paper-text` 或 `abstract` 类型证据
- 证据必须包含：来源类型、文本位置（如 introduction / method / abstract）、内容摘要

## 置信度标准

| 置信度 | 含义 |
|---|---|
| 0.9–1.0 | 论文正文中有明确表述 |
| 0.6–0.9 | 摘要或引言中有间接表述 |
| 0.3–0.6 | 基于上下文推断，需人工审核 |
| < 0.3 | 不建议录入，标记为 `proposed` 等待确认 |

## 里程碑标记规则

- 不得仅凭被引次数标记里程碑
- 需要：高置信度方法关系边 + 后续多篇论文的正文引用证据
- 里程碑标记必须经用户审核确认（`review_status: confirmed`）

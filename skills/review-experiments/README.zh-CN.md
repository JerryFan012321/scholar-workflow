# review-experiments

只读整理和比较已有实验，不重跑实验、不另建看板。明确项目、Run、结果对应的
Attempt 和指标后，返回带档案链接的 Markdown 报告；选择有歧义时确认，不默认选最高分或最新结果。

例如：

> 对比选定的 baseline 和 variant Run，采用各自 primary Attempt 的 accuracy
> 成果。列出全部 Attempt 历史和缺失证据，只返回 Markdown，不运行代码或改项目。

报告先说清结论，配上有依据的结果图和数值，再解释比较条件、配置差异及限制。
没有可用图片或数据时明确说明，不造图、不补跑。实验与执行尝试分开，失败记录保留；
机器ID和完整哈希等核验细节不挤入正文。
单位、评测协议缺失就明确未知，不继承其他 Run 的信息；远端成果不自动下载。
不会虚构统一指标 JSON 格式，也不会把一次结果差值说成统计显著进步。

多实验对比用紧凑表格记录名称、实际执行时间、目的、配置自变量和结果。
变量少时直接列值；变量多时概括关键差异，链接并核对对应执行留存的配置。
未核实的配置、失败与缺失结果保留说明，不能用当前工作配置或猜测补齐。

保存到项目的报告须在 VS Code 中显示图表并支持本地导航，具体见
[项目阅读器契约](../../references/vscode-project-docs.md)。其他阅读器显示成功不能代替这项验收。

详见[报告契约](../../references/experiment-review.md)。本功能自0.43.0提供；
原生阅读和人工实用性评鉴与安装分开。

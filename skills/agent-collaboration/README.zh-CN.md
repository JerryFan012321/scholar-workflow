# agent-collaboration

宿主无关的跨 agent 协作 skill：把同一个、已经获得用户授权的任务拆给可用 agent，并整合它们
的结果。Claude Code、Codex 或其他受支持 agent 都可作为调用方或执行方，不设单向关系。

## 它做什么

- 选择真实可用的协作通道：宿主原生 agent 工具、经验证的目标 CLI，或其他已配置适配器。
- 构建边界清楚的交接包，记录项目规则、当前状态、既定决策、范围、权限、验收标准和停止条件。
- 核对目标 agent 的完成信号和实际产物，再由调用方整合。
- 在每次委派中保持用户原有授权边界，不因跨 agent 而扩大权限。

## 使用

明确提出共同执行或任务接力：

- *“让 Claude Code 和 Codex 分工完成这次迁移，最后整合。”*
- *“把测试实现交给 Codex，你继续改运行时代码。”*
- *“请 Claude Code 接手文档部分，然后在这里完成整个任务。”*
- *“把这个数据抽取子任务交给另一个可用 agent。”*

普通单 agent 工作，以及结果仅为 review 或第二意见的请求，不触发本 skill。

## 支持的通道

优先使用宿主原生协作工具。随 skill 提供的 references 定义了 Codex CLI 与 Claude Code CLI 的
非交互调用协议。其他 agent 只有在当前宿主存在原生工具，或已配置的适配器能明确工作目录、
权限、完成信号和结果通道时才调用。

目标 agent 得到的权限绝不超过调用方已有权限。调用方始终是最终整合者，负责完整验证和面向
用户的统一结果。

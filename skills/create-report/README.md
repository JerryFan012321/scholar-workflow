# Human-facing reports

Use `create-report` for a requested report or a report-shaped communication
deliverable: experiment summaries, progress updates, project presentations,
technical evaluations, delivery summaries or problem reviews. The list is open;
the current communication purpose determines the report.

The [report contract](../../references/report.md) keeps scope and delivery separate
from shared content and writing requirements. The conversation supplies the medium,
audience, materials and any accepted structure. No universal chapter list, length
quota or per-report configuration form is introduced.

Existing experiment reviews, paper analyses, project entry documents and knowledge
notes retain their own formats. Recommendation Reading Reports remain in the
recommendation system. Requested files are delivered as usable artifacts, checked
and shown for human review; automatic checks do not imply acceptance.

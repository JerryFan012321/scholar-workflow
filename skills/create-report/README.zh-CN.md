# 面向人类的报告

`create-report`用于人明确要求的报告，或按本次沟通目的需要组织的报告交付，例如实验汇总、
阶段进展、项目展示、方案评估、结题交付和问题复盘。报告用途保持开放，不按分类自动增加文件。

[报告规范](../../references/report.md)负责范围、已有业务格式衔接和交付，按需引用共用内容与文风要求。
载体、读者、材料和已有模板沿用对话信息，不增设统一章节、字数配额或一套报告配置表。

实验审阅、论文分析、PROJECT和知识笔记仍由所属业务持有格式；Reading Report继续属于推荐系统。
需要文件时交付可用的实际文件，检查后给人查看，再按意见修改；自动检查通过不代表人工验收通过。

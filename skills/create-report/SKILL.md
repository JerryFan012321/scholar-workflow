# create-report

## Result contract

Deliver the requested report in the conversation's selected medium and destination,
using the [report contract](../../references/report.md). It owns report scope,
format routing and delivery; follow its conditional link to the shared content and
writing requirements. Existing business formats and source records keep their own
authority. There is no universal report chapter list.

## Inputs and scope

Use the supplied purpose, audience, materials, medium and accepted template. Reuse
the current task's context; ask only for missing information that prevents a faithful
deliverable. A report request does not authorize running experiments, importing
resources, changing records, publishing or installing tools.

## Completion

Provide the actual requested result, its opening instructions and material gaps.
Follow the report contract's delivery and human-review requirements; a generated
file or passing automatic check does not establish human acceptance. Revise the
report in response to the person's feedback within the authorized destination and
the owning format's update protections.

# Shared content and writing requirements

Use `content-and-style` directly for a requested prose revision, or as a companion
when an owning Skill produces an explanation. It applies the user's confirmed
content, Chinese prose, typography and delivery requirements from one
[runtime contract](../../references/content-and-style.md).

For example: “Apply the shared content and style requirements to this supplied
experiment explanation; keep its data and report structure.” The caller's inputs,
medium, output format and permissions remain in force.

Knowledge construction owns notes and paper analyses; project and experiment
Skills own their documents. This companion supplies no universal report template.
It keeps full explanations in narrative bodies and preserves compact Canvas,
Reading Report and other projection fields. Verbatim excerpts stay verbatim.

Existing content-producing Skills reach it conditionally through the
[human presentation contract](../../references/human-presentation.md#standalone-explanations).
A lookup, status response or machine-only payload does not require a long-form
explanation. A style-only request neither researches new facts nor saves files
without the caller's authorization.

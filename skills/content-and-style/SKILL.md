# content-and-style

## Result contract

Deliver the requested text with independently understandable explanations and the
user's agreed writing style. The owning task or Skill retains its artifact,
structure, evidence, scope and write permissions. Knowledge notes remain knowledge
work; reports remain report work.

Before drafting or revising applicable prose, follow the
[shared content and writing requirements](../../references/content-and-style.md).
Load the sections relevant to the selected medium and requested edit. This companion
can be invoked directly or through another Skill; it does not require another
agent or an additional service.

## Inputs and scope

Reuse the supplied material, intended reader, purpose and requested medium from the
current task. Ask only for information whose absence prevents a faithful result.
An audit request returns findings; it does not authorize a rewrite or a file save.

## Constraints

- Preserve the owning format and required coverage. Full explanations belong in
  the body; a compact Canvas node, card or projection keeps its prescribed scope.
- Preserve verbatim excerpts, facts, values, evidence locators and protected source
  material. Missing source detail remains missing; writing polish cannot supply it.
- Apply only the requested edit and existing write/update protections. This Skill
  grants no import, source acquisition, analysis regeneration, file migration,
  application configuration, publication or installation permission.

## Completion

Return the requested text or artifact in its owning format, with usable sources
and any unresolved content gaps. Deliver actual files when requested; follow the
[delivery and review requirements](../../references/content-and-style.md#delivery-and-review).
Automatic checks, factual support and human acceptance are separate outcomes.

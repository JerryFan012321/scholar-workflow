# 共用内容与文风要求

`content-and-style`可以直接用于指定文本的修改，也可以由编写正文的业务Skill按需调用。
已确认的内容质量、中文文风、字体和交付要求统一放在一份
[运行规范](../../references/content-and-style.md)中。

例如：“按共用内容与文风要求修改这段实验说明，保留数据和报告结构。”
复用当前任务已有的材料、读者、用途和载体，不要求人另填一套表。

学习笔记、论文分析等仍归知识库业务管理，项目和实验文档仍归各自Skill管理。
本Skill不统一章节或套用报告模板。正文保持充分解释，Canvas文字继续简短，
Reading Report保持论文信息、摘要和项目主页范围；原文摘录保持逐字内容。

现有业务入口通过[共同呈现契约](../../references/human-presentation.md#standalone-explanations)
按需使用这套要求。检索、状态回复和纯机器结果无需加载完整讲解要求。
文风修改不授权补造事实、重新生成论文包、修改应用设置或另存文件。

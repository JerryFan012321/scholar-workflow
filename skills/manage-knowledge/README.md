# manage-knowledge

Start from the configured Zotero receiving collection and its human-readable intake
notes. Preserve the person's comments and classification/use instructions, then use
the owning installed Skill for the selected next management operation.

```text
scholar-research recommendations --profile personal intake target
scholar-research recommendations --profile personal intake entries --limit 50
```

The queue contains metadata and prepared context, not automatically imported PDF or
HTML files. Reading it does not create a Vault unit or execute an analysis. Configure
the collection once through recommendation settings or the documented target CLI.
See [runtime entry](SKILL.md) and [intake contract](../../references/zotero-intake.md).

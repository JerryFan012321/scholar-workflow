# 管理实验

让一个实验可以持续补测、修正配方、产生多个结果，并多次进行阶段存档。
Skill 负责可读记录和明确的材料选择，实验仍使用项目自身的配置与运行入口。

配方和代码保持轻量，资产只保存引用。阶段存档时逐项选定配方版本及其结果，
核验所需依赖后，清理两个存档点间未保留的配方、结果和中间材料。
Git 保留轻量历史，不另存完整工作现场。

例如：“清点这个实验的产物，列出远端保留、本地需要和可以清理的内容，再处理已约定的阶段。”
仅比较已有结果时使用 `review-experiments`。

从 `SKILL.md` 开始，按需读取共享契约。附带的标准库工具只输出文件预览并核验是否变化，
不传输或删除文件。实际操作使用原生 SSH、文件工具和 Git，不需要新服务、前端或模型调用。

共享模型、数据集索引与可复用成果遵循[工作区资产池契约](../../references/workspace-assets.md)。
配方引用确切资产版本，只读运行直接复用；修改资产本身才生成可写派生版本。
登记可以保留原位置，搬移与明确选择的传输分别说明范围。
阶段清理检查其他实验的使用关系；材料工具目前不解析资产 ID。

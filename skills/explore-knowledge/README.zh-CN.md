# explore-knowledge

左侧“知识库 → 添加 Vault/目录”支持系统选择、三层检查、必要调整预览与只读连接。
接入只更新当前环境的本机登记；已有正文、解析树、图片与格式保留。未确认论文身份的
文档仍可阅读，但不会成为论文节点。测试须明确选择独立状态和 test 根，详见
[Vault 接入与隔离](../../references/vault-connections.md)。

以可编辑维度、条件和结果组织研究工作，查看带依据的关系与完整资料入口。
这一层引用已有论文单元，不改分析正文、Canvas、sidecar、原文或图片。

点击“引用论文单元”，选择已登记领域并勾选完整论文单元，带入全部声明资产，不创建新论文、
不复制论文包，也不会自动保存。多条条件记录仍挂在同一单元上；论文资产归属在这里只读，
通过原有流程维护。表单校验失败时保留输入和原有未保存草稿，不自动删除或转换旧记录。

```sh
scholar-workflow knowledge explore --root /path/to/selected/folder
```

界面使用本机动态端口；处于 cmux 时尝试在那里打开，否则使用普通浏览器。
终端保持运行，按 Ctrl-C 停止；加 `--no-open` 只显示本次会话地址。
窗口位置不决定文件权限，也不要求 workspace 绑定。

维度、工作、条件化记录、关系与保存视图统一保存在
`.scholar-workflow/exploration.yml`。初始四个维度可扩展；新增定义后再填写对应取值。
筛选先匹配同一条研究记录，再汇总工作，避免把不同实验的基座、任务和结果拼在一起。
条件与结果一起展示，作者报告、本地复现、独立评测和分析判断分别标注。

选中论文后，在右侧已登记的 Markdown 资料上点击“预览”。原文摘录标题和来源按钮保持
可见，点击标题展开完整摘录及加粗依据；已登记本地图像与图注就地显示。缺失或不支持的
图片保留原因，远程图片不自动加载。正文只读；Canvas 等资产仍通过“在原生应用打开”编辑。

资料清单保留所有明确登记的本地／在线入口及缺失诊断。Markdown 导出提供同一组研究定位、
资料、条件结果和关系导航，供 Obsidian 阅读；命令只向终端输出，不自动插入论文包或新建导航页。
从界面和外部编辑器保存时以当前版本检查冲突，发生冲突后重读再处理。

精确命令、文件格式和现有边界见[运行契约](../../references/knowledge-exploration.md)。
本批开发完成不代表已正常安装、原生链接已逐项打开或人工使用体验通过。

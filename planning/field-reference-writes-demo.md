# 领域引用增删：实际合成 CLI 展示

这是开发树 CLI 在独立合成目录中的实际输出，不是已安装产品或正式 Vault 操作。
来源输入可由 `test_field_reference_write_cli.write_scope` 与 `ownership_scope` 重建；
通过 `_selection(language='zh')` 调用 `reference-plan`，按其摘要调用 `reference`，
再对同一引用调用 remove 的 `reference-plan`。全部目录在展示后清理；下方摘要只对应
当次临时输入，不能用于其他资料。没有复制论文、调用外部应用或改正式知识库。

```text
资料文件：research/resources/papers/ownership/Analysis.md

状态：待确认

只修改引用方清单；原文、解析树及目标归属不变，不复制或删除资料。

## 确认摘要

`3fd2a6fbc19957ec54661b317c4bc74e52855aae04a00634611472b201ff2f10`

尚未写入。
```

## 供人审阅的事项

阅读以上新增与移除预览：应能辨认所选领域、引用名称、用途和只改清单的影响；
用途相同的两条引用仍能由名称区分。这里不证明 Obsidian 点击导航或视觉排版已验收。
新入口尚未发布安装；正常安装 CLI 当前仍为 0.42.0。

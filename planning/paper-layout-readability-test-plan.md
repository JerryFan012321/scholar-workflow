# 单篇解析树：间距候选检查计划

## 输入、对象与影响

只用test模范目录中现有V-JEPA2解析树，108个文本节点、107条边、完整五分支，
以及节点明确引用的两幅已有PNG。正文、baseline、科学内容、PDF、Zotero与服务不改。
新版只放test“上层组合审阅-20261010/版式修订/论文解析树”，不替换原图。
这是布局设计提案，不是新分析、正式成对更新或已安装skill执行结果。

## 预期（生成前固定）

- 节点/边集合及数组顺序、全部文字、链接、宽高、x、metadata、路由和父子关系不变。
  只允许节点y及五个主分支标题的背景颜色变化；不是删内容或缩小字体来求紧凑。
- 五分支保留原顺序；主分支间留128px，章节内主要子树64px，带孙节点的组32px，
  最内层叶节点16px；测量与放置使用同一间距。父节点纵向对准首末子节点中心。
  整体仍满足2:1，所有框原点击留白、对齐、无重叠、直角无交叉/穿框要求不放宽。
- 原图及受保护包全部文件字节保持；两幅节点引用图原样复制到候选attachments。
  PDF与正文入口不重写，正文反链仍指向已存在的原配套Markdown，说明中明确这一点。
- 候选不加正文、批注、证据画廊或额外语义节点，不成为新知识归属。
- 输出可编辑Canvas与可见总览/局部预览；预览明确不是Obsidian原生效果或人工通过。

## 检查与完成边界

先记录输入包摘要，再通过开发期独立脚本生成一次新候选；比较所有非白名单字段，
执行现有几何检查和独立关系/矩形/正交路由复核，记录实际边界与间距。
若不满足预期则报告失败，不盲调预期或扩大跨度上限。检查生成脚本及必要的
v5几何测试；不改默认生成器及冻结旧几何预期。无需整库、真实批量或完整业务重跑。

用现有bundled headless浏览器输出静态总览与局部预览，不启动/操作原生应用，
不访问网络，不加载远端图片，不点击PDF协议。预览保留足够字号；图形仅作为查看
辅助，可编辑Canvas是主要交付。浏览器文字测量发现不足就报告，不以截图掩盖裁切。
可见结果和失败记录保存到同一test目录；开发仓库只记录定位/检查摘要。

人工评鉴在会话给出文件、打开方法：Obsidian test Vault打开候选，检查五分支区分、
模块内四子槽辨识、对齐/无交叉、文字点击留白与编辑；点任一正文链接应到原配套
正文与对应位置。明确通过前待人工；正常发布安装仍须独立授权。

## 首版失败后的第二版说明（执行前）

首版5项手算单测通过，但实际完整图为5596×11608，超过2:1；未保存候选，
不改长宽比要求，首版不算通过。主要开销来自章节内64px在多组之间反复累加。
第二版独立调整设计：主分支96px、章节内40px、有孙节点组24px、叶节点16px。
仍严格有级差且不扩横向空白。手算合成两章节的66px节点图：两子树各172px，
总高440px，叶位置0/106/268/374，章节53/321，根187；这些预期在再执行前固定。
输入、非几何守恒、原件、图片和所有硬门禁不变；再次超限即记录失败，不能放宽标准。

## 分区对照版说明（执行前）

第二版间距方案几何通过但高10952、比原图增加19.8%，不认定满足整体空间或美观。
独立分区对照不改任何原节点坐标/宽高/文字/顺序/边，只改五个主标题底色，并在原节点
之前增加五个原生group作为背景容器，默认展开、不添加语义或影响节点预算核算。
分区外框上20/下12px沿用原章节32px间隔，不改变原图的密集叶间距；不得宣称已解决
所有布局问题。各组完整包住自身子树，不跨入其他章节节点。输出到独立“论文解析树分区版”。
几何检查仍以108原语义节点与107原边为准，并分别核对五个容器范围。原生折叠体验待验。
bundled Playwright缺默认浏览器，首轮预览启动失败；不下载安装浏览器，改用已存在的
本机Chrome executable作headless离线预览，仍不启动或操作用户原生窗口，不读用户profile。

## 预览修正检查（执行前）

两版预览测得108个文字框未裁切，但4框缺21px点击余量；不以此宣称全部可读性合格。
局部截图需要独立页面并归零滚动，避免总览缩放后页面状态影响裁取。输入仍是同一候选；
局部包含流程模块1及四个直接子槽，五个实际DOM边界必须均落在四周24px留白内。
以“-修正”后缀新存预览，不覆盖原检查记录、不动Canvas。定向回归为新开发脚本6项、
既有v5结构/容量/安全测试72项，预期共78项通过；Ruff与diff检查无错误。
此外重算原包65文件摘要，应与本轮开始前完全一致。所有结果仍仅离线静态检查，
原生显示/可编辑性/实际链接点击和美观待人工评鉴。

## 分区失败后的最小修正（执行前）

独立检查发现方法与实验的组范围重叠131px，实验框误包住一个方法节点并碰到另一个；
原节点未重叠，但分区候选不通过。修正版仅把每章全部节点作同量纵向平移，组之间
至少24px；章节内部相对位置、内容、边和链接不变，根标题再对准首末章节标题中心。
不重排章节内节点、不扩跨度标准；新目录“论文解析树分区修正版”保留前两案及失败记录。
四个点击留白不足框只增宽：根104→160、既有方法344→444、两项具体做法424→524与
464→564。其余宽高保持；浏览器测量仍需证明无裁切且每框至少21px余量，未达到即报告。
新增独立手算用例：66px高两章的组各98px、第一组y=-20、第二组y=102，间距24px；
第二章整章移动122px，根y=61。另查仅指定框增宽、未知/缩小宽度拒绝，合计81项定向测试。
以实际内容守恒、独立组范围/正交边检查、离线预览、65原包文件字节不变为边界。

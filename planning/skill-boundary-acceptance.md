本切片只改运行文案、格式入口与对应 eval，不改 CLI、schema、生成器或已有人类样张。
以下输入与预期在测试前手写；它们不是模型实测结果，也不证明新版 Canvas 已实现。

## 本轮变化与保留

| 入口 | 纠偏后的要求 | 不改变的契约 |
|---|---|---|
| survey / lineage | 已有输入跳过搜索、入库；缺少输入才调用前置能力 | 文献树两种拓扑、账本、反链、预览/写入边界 |
| feed | 用户选中论文不等于入库；可直接调用 owning skill，不指定必经 agent | 临时报告、只略读 shortlist、入库前判重 |
| knowledge | 分析更新遵守成对 baseline/CAS；不按普通追加笔记处理 | 论文五分支和具名子节点、行内证据、链接、原文摘录、单篇目录 |
| audit | 对话默认可读报告；JSON-only 显式选择 | 只读、明确范围、逐项证据、不可用源不算正常 |
| 共同呈现入口 | 当前论文模板与 v4 兼容契约明确分工 | 旧产物不静默刷新、不凭旧测试冒称新格式通过 |

## A：合成行为评鉴（8 项；批准后执行）

只向独立评鉴者提供下列请求、选定运行文件与合成输入，不提供本表的预期答案。
允许读取这几份文案；禁止访问真实业务数据、网络、执行 CLI、写 Vault 或调用业务 skill。
任务是输出路由/交付提案或合成报告，不是假装已经创建正式文档。

| ID | 手写测试请求与输入 | 预期与失败判据 |

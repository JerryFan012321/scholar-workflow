# 推荐阅读与设置 UX 实施结果

日期：2026-11-10。0.52.0 未发布候选，工作树 `recommendation-alphaxiv`。
调研依据见[使用体验审查](recommendation-ux-review.md)；本轮只调整推荐前端及会话草稿范围标识，
不增加模型执行器、业务状态或真实推荐数据。

## 已实现

| 区域 | 当前行为 |
|---|---|
| 首页 | 保留紧凑内容，直接打开原文、稍后看；低频忽略放进“更多”。可撤销选择使用返回的新revision |
| 连续阅读 | 上一条/下一条、当前序号、跨分页、J/K、Escape与浏览器返回；输入框中不抢快捷键 |
| 阅读位置 | 同条更新保留滚动、展开部分和焦点；换条回顶部；返回列表定位到条目 |
| 筛选与热度 | 次要筛选折叠，已选条件可逐项移除；热度用短行，采集诊断按需展开 |
| 设置 | 齿轮进入来源、上下文、入库记录；导航与浏览器历史协调，分组标题获得焦点 |
| 长文本 | 未修改时保存禁用；编辑/保存中/成功/失败明确；取消确认仅在有改动时出现 |
| 草稿与冲突 | 查看最新版只作对照，不覆盖草稿；显式采用新版保存基线。同origin会话刷新恢复，按profile/pool隔离 |

真实书目入库继续要求摘要/总结审阅、选择、目标预览与明确确认。快捷稍后看、评价和保存设置均不自动入库。
浏览器草稿不保证跨动态端口、跨浏览器或重开会话恢复。

## 独立检查

输入为合成候选、模拟接口和延迟响应；先定义阅读、精确revision撤销、草稿、错误与导航预期，
再运行定向检查，不访问真实外部provider。最终369项通过，11.84秒；三个JS语法、22个变更Python
文件的Ruff与diff检查通过。未重跑全项目；扩展到未改推荐文件的lint曾检出6项既存导入/unused问题，
未顺手修改。早期失败分别涉及未实现动作、测试导入、旧断言和mock DOM缺失，回执保留。

整合审阅另补两种可复现竞态：

- 跨页历史恢复请求晚到时，若已进入设置，不再重新打开详情；覆盖popstate与点击设置两条路径。
- 来源要求保存后刷新目录尚未结束时，保存锁保持；不会提前放开输入或启动第二次保存。

## 同一 test 对象的浏览器结果

位置：`test/Scholar Workflow 实验/alphaXiv推荐与入库-20261109/`。

1. 对项目合成推荐“稍后看→撤销”，回到原未处理状态。
2. 详情第2→3→2条，位置与内容一致；浏览器返回列表并定位原标题。
3. 设置上下文填入未保存文字，查看最新版后草稿仍在；同origin刷新恢复；取消后回到第1版。
4. 类型筛选为项目，显示1项与可移除条件；移除后恢复4项，次要筛选收起。
5. 读回确认四条正文、评价、审阅、决定及旧模拟入库事实不变。选择/撤销只增加项目revision及更新时间。

合成排序的输入因此发生变化，正确显示过期并回退发布日期；没有偷偷重新提交排序。

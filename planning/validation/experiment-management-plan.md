# 实验管理：本轮输入与验收范围

日期：2026-11-15。开发验证，不是安装态或真实科学实验验收。

## 输入与对象

单个 test Vault 样例项目，模拟本地主项目和远端执行工作区；不连接服务器。
两项可计算的小实验：采样数量对直线参数估计的影响；异常观测下两种估计方式的差异。
第一项包含初次测量和补充测量，保留配方/结果对应及轻量 changelog；第二项提出不同问题，单独登记。
数据为确定性生成的合成数据，结论仅限样例。原有 test 论文单元、项目、人工修改与配置不改。

## 实现与测试分界

先新增运行契约、按需 Skill、只读材料清单工具及独立测试，再执行验证。
工具只核对明确文件、用途选择、大小和校验值，并生成回传/清理预览；不复制、删除、连接服务器或执行配方。
阶段清理和实际传输由已授权的原生工具完成，操作日志的恢复规则由 Skill 约束。
本轮不添加未经使用验证的全自动生命周期服务。已有 Run/Attempt 程序不重写。

## 预期与检查

1. 不同配方结果有各自的配置、代码版本及条件，补测仍在原实验；Git不包含模型与批量中间产物。
2. 主入口同处展示条件、结果、占用和保留状态；核心实验为待人选择，禁止代替用户选择。
3. 材料预览只回传明确选定的结果及解释材料；模型、原始不可读数据、临时文件即使很小也不能回传。
4. 绝对路径、越界、重复、符号链接、已变化文件、未知用途和互相矛盾的选择均有明确诊断；不产生破坏性副作用。
5. 已保存清理预览和阶段记录先于样例临时文件清理；仅清理本轮生成且校验未变的临时物。
6. 结果直接链接配方/图/数据，上级逐层维护到主项目；阶段存档、材料回传、清理、人工认可分别表述。
7. 旧 Run/Attempt 契约和程序维持可读；运行文档明确其兼容范围，不将旧冻结规则推广到新实验。

## 具体执行

- 用标准库 unittest/pytest 检查只读工具的正例与安全反例；每个测试根位于 test Vault 已有 `Scholar Workflow 实验/_工作/experiment-management-checks`。
- 用合成脚本生成确定性 CSV、图、条件和记录；显式选择少量结果复制到本地示例，再对比 hash。
- 只删除本轮创建且清单批准的可再生临时文件；模型示意文件留在模拟远端。无真实模型或数据下载。
- 检查 Markdown 本地链接、Git跟踪边界、Skill引用及受影响项目契约。
- 在会话展示入口和图，告知人工检查方法。未获用户评价前仍为待人工评鉴。

## 交付

运行 Skill 与 reference、只读材料预览工具、test Vault 的一个持久样例、独立测试结果。
尚未发布或正常安装；已有安装不因开发样例改变。后续安装态验收需使用正常发布安装链路。

用户进一步限定：本轮专注未来新实验，旧档案调整后续单独处理。样例只创建新对象，不迁移现存实验。
展示修订只重绘已有数据的3张图，英文采用Times New Roman、横轴标明实际条件；不重跑测量，更新本地副本核对记录和相关入口。

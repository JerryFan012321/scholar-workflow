# 实验档案交付缺口：独立输入与预期

## 已核事实与本轮范围

真实毕设只有报告、没有本地Run档案；本轮只修插件侧交接和显式清单检查，不连接服务器、
读取凭据、迁移真实项目、写Vault或Zotero。现用0.46.1保持，不以源码测试代替安装验收。
缺少真实原始证据时，不从人类报告重建虚构配方/时间/hash或接收回执。

## 先固定的合成输入

复用test_project_collection_plan.py既有单Run fixture：一父一子、固定身份、配置/环境/
数据快照，以及planned/running/succeeded/failed/interrupted五条Attempt。脚本含DO NOT
EXECUTE，不运行脚本或模型。每个用例在pytest隔离目录创建自己的输入，不建Vault副本。

| 输入变化 | 必须观察到的结果 |
|---|---|
| 父侧只有docs/report文字与服务器路径，未接收Run | 普通查询保持原兼容；显式要求该Run时JSON为partial、列出缺失Run、exit6 |
| 已有子归档目录但为空 | 显式清单检查仍失败，不因目录存在通过 |
| 已接收一Run，清单还包含另一Run | 有效Run及五状态保留，缺的精确列出、exit6 |
| 已接收Run的配置字节被改 | 无效行保留，exit6，不修复或覆盖原件 |
| 完整接收所选Run | exit0，原始commit/配方/全部状态/本地引用保持；不认证实际执行或科学正确性 |
| 只有旧generic身份与报告，没有management声明 | exit2，提示前置条件缺失，既有文件不改；不能据此自动迁移 |
| 要求Run清单但未明确child，重复/非法Run ID | exit2，输入在读档案前拒绝；不擅自选择child |

清单是本次调用参数，不建立另一份实验登记。检查只证明明确选择的本地归档存在与完整性，
不能发现未登记远端实验、证明全部实验都在清单中或证明指标/图片已经满足科学审阅需求。
普通只读查询仍允许空库，不将正常空查询变成普遍错误。

## 操作与证据

先新增上述CLI回归并运行所选用例，保存失败原因；再最小修改collected/CLI。验证前后
父子文件集合及字节完全一致，禁止子进程/配置读取；读输出原始JSON而非仅看打印字样。
定向运行collection、management、CLI兼容及eval结构，必要回归独立记录。检查skill文案
和链接不等于宿主行为实测；新接收/交付行为outcome保持pending。

本轮不改变论文分析、Canvas、项目六节、同表比较或实验身份模型。真实SSH传输、旧项目
角色接入和正式档案接收仍须当前证据与独立授权；后续只在现有test单对象安装态续验。

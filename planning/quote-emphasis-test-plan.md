# 摘录直接证据强调：独立测试方案

对象仅合成论文IR及pytest隔离目录，沿用已有v4/v5框架。不调用外部应用、不改Vault、
provider、原PDF、项目、实验或安装。用户已批准本轮合成测试；发布安装独立判断。

## 先准备的输入和预期

合成SOURCE保留三个完整句子：固定相机条件；72%成功率/50次实验/同一条件；未测试
其他条件。只选第二个完整句为直接证据。独立手写EXPECTED规定该句粗体，前后句正常
显示，句子/数值/条件/来源链接逐字不变。推断例只标“推断依据”，不伪装为作者结论。

## 操作和通过标准

1. 先跑新增用例，旧模型拒绝新字段应RED；仅实现SourceSpan可选quote_emphasis和
   既有quote renderer的格式投影，空/省略新字段保持旧baseline序列化及输出。
2. 正常quote原文不写Markdown标记；强调片段必须在quote中唯一、精确、非空、不重叠。
   拒绝改写/不存在/重复歧义/重叠/无quote/非法类型及不可显示的旧profile组合。
3. 中文/英文、claim/point、PDF/Markdown来源、Unicode/多行和源文特殊语法分别检查；
   保留完整上下文和来源，仅批准的片段加粗，不形成新链接/HTML或机器注释。
4. 正式conformance拒绝去掉/移动/替换强调；focused更新保留未选分支、人类内容，
   完整Canvas JSON不变。不同evidence类型继续有不同可见说明。
5. 公共schema与model往返通过；保留仅model可校验的片段语义边界，不冒称JSON Schema
   可以比较任意quote子字符串。受影响摘录/来源/更新/图片及eval schema定向回归通过。
6. 由于SourceSpan是共享模型，定向用例通过后运行一次完整unit/contract合成回归，检查
   既有批次、提交、安全与兼容路径。不做真实业务，不发布安装；未经测试不准备提交。

实际结果单独记录。手写fixture可供格式审阅，但不是安装态、人类通过或科学认证。

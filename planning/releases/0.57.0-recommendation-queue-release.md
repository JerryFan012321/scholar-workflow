3. 接收聊天使用消息提供的准确HOME执行start，保留已有背景并将指定意见消化到context。
4. 读回context摘要、提交complete；中央status为completed，start/complete时间与实际文件可核对。
5. recommended内容不变，不产生第二个推荐；中央curator仍独立待消费；重复sync不重复发送。
